# MoxToGame v12.42 — Prompt 08
## Conversion d'un effet réel vers ChoiceService + continuation

### Objectif
Convertir un seul effet réel existant, `searchLibrary`, afin qu'une résolution puisse être suspendue pendant le choix d'une carte puis reprise exactement après la réponse UI.

### Base
- Version de départ : v12.41
- Effet réel choisi : `searchLibrary`
- Cartes réelles concernées : Aladdin's Lamp et Ring of Ma'rûf utilisent ce handler.

### Défaut avant correction
`searchLibrary` appelait `ctx.api.choose(...)` sans continuation. Lorsque le choix humain n'était pas immédiatement disponible, l'effet retournait `null` et la suite (retrait de la bibliothèque, déplacement en main, mélange et événement) n'était pas exécutée.

### Correction
Le handler transmet maintenant une continuation à `ctx.api.choose()`.
La continuation :
1. récupère l'état actuel de la bibliothèque ;
2. identifie la carte choisie par `uid`, puis `objectId`, puis `id` comme repli ;
3. retrouve l'objet runtime actuel ;
4. le retire de la bibliothèque ;
5. le déplace vers la main ;
6. mélange la bibliothèque ;
7. émet `librarySearched`.

Aucune copie capturée avant l'attente n'est utilisée comme autorité de reprise.

### Test
`tests/test-v12-42-search-library-continuation.mjs`

Le test vérifie :
- suspension réelle ;
- bibliothèque et main inchangées avant réponse ;
- réponse UI simulée par une copie portant le même UID ;
- résolution par UID de l'objet runtime ;
- déplacement vers la main ;
- mélange ;
- événement `librarySearched` unique ;
- finalisation unique de l'objet de pile.
