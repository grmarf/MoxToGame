## Méthode de sélection

Un lot de **20 cartes** sorts/enchantements/auras a été audité. La règle appliquée est stricte : une carte n'est certifiée que si le comportement complet correspondant à son texte Oracle peut être prouvé par le pipeline réel GameFacade/Stack.

### Carte certifiée

1. **Timetwister** — `wheel`
   - Oracle vérifié : chaque joueur mélange main + cimetière dans sa bibliothèque puis pioche sept cartes.
   - Coût `{2}{U}` confirmé.
   - Le sort lui-même n'est pas inclus dans le mélange et rejoint le cimetière après résolution.
   - Test E2E nominal + cas limite avec mains/cimetières vides.
   - `effectStatus` passe à `implemented`.

### Candidats écartés

2. **Blaze of Glory** — écartée : l'implémentation `mustBeBlocked` disponible ne reproduit pas la cible et les restrictions temporelles/« block any number » de l'Oracle.

3. **Purelace** — écartée : l'Oracle cible un sort **ou** un permanent ; le handler `changeColor` existant ne couvre actuellement que les permanents.

4. **Reverse Damage** — écartée : l'Oracle filtre la prévention sur une **source choisie** et sur le prochain événement seulement ; le shield générique actuellement disponible ne mémorise pas cette source.

5. **Righteousness** — écartée : l'Oracle exige une créature bloqueuse ; la validation actuelle de `pump` ne possède pas ce prédicat de ciblage.

6. **Braingeyser** — écartée : l'Oracle cible un joueur ; le handler `draw` actuel tire toujours pour le contrôleur du sort.

7. **Drain Power** — écartée : l'Oracle force l'activation des capacités de mana des terrains de la cible avant de transférer le mana ; le handler actuel ne fait que vider le mana déjà présent.

8. **Power Sink** — écartée : le contre conditionnel est présent, mais l'effet Oracle comprend aussi l'engagement des terrains et la perte du mana non dépensé lorsque X n'est pas payé.

9. **Siren's Call** — écartée : l'effet existant `forceAttack` ne couvre ni la fenêtre de lancement ni la destruction à l'étape de fin des créatures non attaquantes.

10. **Spell Blast** — écartée : le handler `counterCMC` existant utilise l'ancienne forme `_kind: 'stackItem'`, alors que la normalisation réelle de cible de résolution fournit `kind: 'stackItem'`. Un essai E2E a laissé le sort ciblé sur la pile au lieu de le contrecarrer.

11. **Volcanic Eruption** — écartée : le handler `destroyXMountains` détruit les montagnes mais ne réalise pas les blessures globales égales au nombre de montagnes effectivement mises au cimetière.

12. **Warp Artifact** — écartée : le câblage existant prépare un trigger `upkeepStarted`, mais la condition `controllerUpkeep:false/sourceSelf:true` n'est pas une condition générique actuellement reconnue par le collecteur de triggers.

13. **Earthbind** — écartée : l'Oracle inflige 2 blessures à l'entrée si la créature a le vol, puis lui fait perdre le vol ; le descriptor actuel ne réalise que la perte du vol.

14. **Fissure** — écartée : l'Oracle permet de cibler une créature **ou un terrain** et interdit la régénération ; le descriptor actuel est limité à `destroy` sans cette restriction complète.

15. **Hymn to Tourach** — écartée : l'Oracle cible n'importe quel joueur ; le handler `discardRandom` actuel impose l'adversaire.

16. **Natural Selection** — écartée : l'Oracle permet de regarder les trois cartes du dessus d'une bibliothèque et d'en mettre éventuellement une au-dessous ; le handler `lookTop` actuel expose les cartes mais ne permet pas l'opération optionnelle complète.

17. **Detonate** — écartée : l'Oracle impose une cible artefact de valeur de mana X et inflige ensuite X blessures à son contrôleur ; le handler `destroy` actuel ne couvre ni la valeur X ni les blessures secondaires.

18. **Guardian Angel** — écartée : le descriptor `regenerateShield` ne transporte pas la valeur X de prévention de l'Oracle.

19. **Blessing** — écartée : le texte de la base est incohérent avec son descriptor (`+1/+1` dans le texte, `+3/+3` dans l'effet), et le chemin Aura réel ne permet pas actuellement de certifier proprement l'attachement par un lancement réel.

20. **Howl from Beyond** — écartée pour ce lot : le handler `pump` reçoit `power: "X"` et le runtime de modification testé produit une valeur non numérique ; le comportement X n'est donc pas certifiable sans modification moteur.

## Point important sur les auras

Un test réel de lancement de `Giant Strength` a montré que le chemin actuel de résolution ne marque pas l'enchantement comme Aura et ne renseigne pas `attachedTo` lorsque `type` vaut `Enchantment` et `subtype` vaut `Aura`. Les auras ne sont donc pas certifiables dans ce lot sans toucher au moteur de pile, ce qui est explicitement interdit par le Prompt F.

`Weakness` et `Giant Strength`, bien que leurs descriptors soient simples, restent donc volontairement hors certification de ce lot. Ils avaient déjà fait l'objet de scénarios de test historiques, mais cela ne remplace pas une preuve du lancement/attachement réel exigée ici.
