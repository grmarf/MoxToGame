# V12.72 — Chemin unique pour les zones et les dégâts

## Zones (ZoneManager)
- `ZoneManager.place()` : chemin unique pour un objet hors zones suivies (sort sur la pile). Sort résolu, contrecarré ou annulé : identité conservée, remplacement de changement de zone, événement `zoneChanged` (from:'stack'). Remplace trois replis directs (stack.js x2, putCounteredInGraveyard).
- `ZoneManager.changeController()` : Control Magic, Steal Artifact, vol jusqu'à la fin du tour, fin d'un octroi de contrôle. Même objet (uid conservé), événement `controlChanged`.
- Mind Bomb / searchLibrary : la carte n'est plus retirée avant `zones.move` (« Objet introuvable » : la carte disparaissait du jeu).

## Dégâts (ReplacementService)
- Hurricane, Ifh-Bíff Efreet, Pestilence (`damageAllCreaturesAndPlayers`), Psionic Blast (créatures) et les dégâts d'entretien (Force of Nature) passent par `applyDamageToPlayer/Permanent` (prévention, protection, remplacements).
- Repli de l'API de pile sans ReplacementService : appliquait un résultat fictif sans effet ; applique désormais réellement vie / dégâts marqués.
