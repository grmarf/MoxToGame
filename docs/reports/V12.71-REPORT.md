# V12.71 — Vrai choix du joueur pour counterUnlessPay (Force Spike / Power Sink)

- counterUnlessPay (atomic-effects.js) : plus de paiement automatique pour le joueur humain. Un choix ChoiceService ('pay' / 'decline') est posé ; la résolution reste suspendue jusqu'à la réponse. Paiement impossible -> contrecarré sans choix. L'IA paie seule dès qu'elle le peut.
- BUG P (stack.js, api.choose) : pendant la résolution d'un contresort, le « haut de pile » est le sort ciblé, pas le contresort. La reprise après choix se rattachait au mauvais élément (sort ciblé retiré de la pile / contresort resté bloqué). On privilégie désormais l'élément en cours de résolution.
- UI : libellés « Payer » / « Ne pas payer ».
- tests/test-v12-84 (5 scénarios), vérifié par mutation (paiement auto réintroduit, mauvais item réintroduit : les deux sont attrapés). test-v12-79 (scénario 3b) aligné sur le choix explicite.
