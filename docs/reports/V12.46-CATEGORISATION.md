# V12.46 — catégorisation ciblée du prochain lot

Cette passe n'a pas reclassé les 843 cartes restantes de manière arbitraire. Elle a porté sur les capacités activées candidates et a appliqué le critère du prompt : effet directement exprimable par un handler déjà enregistré, sans nouveau mécanisme.

## Groupe A — candidates simples retenues / prochaines candidates

Le lot certifié de cette passe contient 16 cartes. Les familles d'effets validées sont :

- `pumpSelf` / `pump` : Dragon Engine, Carrion Ants, Goblin Flotilla, Wall of Opposition, Killer Bees, Pavel Maliki, Wyluli Wolf, Ghosts of the Damned.
- `gainLife` : Fountain of Youth.
- `addKeywordUntilEnd` : Flying Carpet, Order of Leitbur, Order of the Ebon Hand.
- `tapTarget` : Staff of Zegon.
- `damage` : Tracker, Crimson Manticore.
- `forceAttack` : Nettling Imp.

## Groupe B — écartées de cette passe

Exemples significatifs :

- Drudge Skeletons / Wall of Bone / Will-o'-the-Wisp / Uthden Troll / Clay Statue / Diabolic Machine : régénération implicite de soi incompatible avec le handler actuel sans modification moteur.
- Deathgrip : cible de sort sur la pile incompatible avec l'adaptation actuelle sans modification moteur.
- Thorn Thallid / Feral Thallid : compteurs de spore obligatoires.
- Armor Thrull : coût de sacrifice + marqueur +1/+2, différent d'une simple pompe temporaire.
- Elvish Scout : le texte Oracle ajoute prévention des blessures de combat et cible une créature attaquante contrôlée.
- Elvish Hunter : le texte Oracle signifie que la créature ciblée ne se dégage pas à sa prochaine étape de dégagement ; un simple `tapTarget` est insuffisant.
- Homarid Warrior : l'activation donne le linceul, empêche le dégagement suivant et engage la créature.
- Standing Stones : choix de couleur + engagement + paiement de 1 PV, donc structure de coût plus riche que le champ actuel.
- Vampire Bats / Fire Drake : restrictions de fréquence (« pas plus de deux fois par tour » / « une fois par tour ») non représentées par les handlers simples.

Ces cartes restent donc hors certification tant qu'une représentation existante ne suffit pas à prouver leur comportement complet.
