## Vérification Oracle et corrections de texte

Les textes ont été confrontés à des sources de cartes historiques/Oracle avant certification.

Points notables :

- `Order of Leitbur` et `Order of the Ebon Hand` avaient dans la base une seule capacité de pompe alors que leur texte Oracle comporte également l'activation donnant l'initiative. Les deux capacités ont été ajoutées.
- `Elvish Scout`, `Elvish Hunter`, `Thorn Thallid`, `Armor Thrull`, `Homarid Warrior`, etc. ont été volontairement écartées après vérification car le texte réel comporte des coûts, restrictions ou mécanismes supplémentaires absents des handlers simples envisagés.
- `Standing Stones` a également été écartée : son texte réel comprend `{1}, {T}, pay 1 life`, et non le simple `{1}` présent dans la base.

## Deux faux candidats découverts pendant l'audit

### Régénération

Plusieurs cartes semblaient idéales (`Drudge Skeletons`, `Wall of Bone`, `Will-o'-the-Wisp`, `Uthden Troll`, `Clay Statue`, `Diabolic Machine`).

Elles n'ont finalement pas été certifiées. Le handler existant `regenerateShield` attend une cible explicite, alors que ces capacités ciblent implicitement la source elle-même. Le chemin d'activation actuel ne fournit pas automatiquement cette cible implicite au handler. Ajouter une rustine dans les données aurait produit une fausse certification.

### Deathgrip

`Deathgrip` possède déjà `counterSpellColor`, mais son adaptation de cible des objets de pile n'est pas compatible avec la forme réellement fournie par `#normalizeTarget` : le handler attend `_kind === 'stackItem'`, tandis que la normalisation produit `kind: 'stackItem'`. L'activation ne contrecarre donc pas réellement le sort dans le scénario E2E. Il reste hors lot plutôt que de modifier `stack.js`, explicitement hors scope.

### Mutation test

Le `pumpSelf` de `Dragon Engine` a temporairement été muté de `+1/+0` à `+2/+0`.

Résultat : le test a échoué comme prévu avec `actual { power: 2, toughness: 0 }` contre `expected { power: 1, toughness: 0 }`. La correction a ensuite été restaurée.
